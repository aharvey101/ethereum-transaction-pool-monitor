WHAT WAS BUILT
================================================================================

A production-ready Ethereum mempool monitor in Rust that:

1. Connects to your local Ethereum node via JSON-RPC
2. Fetches pending transactions from the mempool every 2 seconds
3. Displays transactions in a beautiful terminal UI
4. Allows navigation and scrolling through transactions
5. Shows connection status and updates in real-time
6. Handles errors gracefully with user-friendly messages

USAGE INSTRUCTIONS
================================================================================

Prerequisites:
  • Rust installed (https://rustup.rs/)
  • Running Ethereum node with JSON-RPC enabled

Building:
  cargo build --release

Running (default localhost:8545):
  cargo run --release

Running (custom RPC URL):
  ETH_RPC_URL=http://your-rpc:8545 cargo run --release

Keyboard Controls:
  ↑/↓           - Navigate through transactions
  Page Up/Down   - Scroll faster
  q / ESC        - Quit application

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Connection Issues:
  • Verify Ethereum node is running
  • Check RPC URL is correct and accessible
  • Ensure port 8545 (or custom) is open
  • Try: curl http://localhost:8545/

No Transactions:
  • Normal during low network activity
  • Try monitoring during peak hours
  • Switch to Sepolia testnet for more activity
  • Some RPC endpoints may not support eth_pendingTransactions

Terminal Rendering Issues:
  • Resize terminal window
  • Check terminal color support (needs 256 colors)
  • Try different terminal emulator
  • Ensure crossterm backend is supported

Build Issues:
  • Update Rust: rustup update
  • Clean build: cargo clean && cargo build
  • Check disk space: >500MB needed
